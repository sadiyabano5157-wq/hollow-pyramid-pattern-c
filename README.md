# ⭐ Hollow Pyramid Pattern in C

## 📌 Description
This program prints a hollow pyramid star pattern using nested loops and conditional statements in C language.

---

## 💡 Pattern Output
Enter rows: 6
     *
    * *
   *   *
  *     *
 *       *
***********

---

## 🧠 Concepts Used
- Nested loops
- Hollow pattern logic
- Pyramid alignment
- Conditional statements

---

## ⚙️ Logic

- First loop prints spaces
- Second loop controls pyramid width using:
  `2*i -1`
- Stars are printed on:
  - left side
  - right side
  - last row
- Inner positions print spaces

---

## 💻 Language Used
- C Programming Language
